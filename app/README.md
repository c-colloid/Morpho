# Morpho アプリ

Markdown で書いた原稿から PowerPoint スライドを作る iPad アプリ。
現在 **0.6.4**（[変更履歴](CHANGELOG.md)）。
プロジェクト全体の紹介は [リポジトリのトップ](../README.md) にあります。

開発サーバでの実行・ビルド・検査など開発者向けの情報は
[`DEVELOPMENT.md`](DEVELOPMENT.md) へ。

## インストール

App Store 未公開のため、サイドロードで入れます。

**必要なもの**

- iPadOS 15.1 以降の iPad
- [AltStore](https://altstore.io/)（同一 Wi-Fi の PC で AltServer が必要）または
  [SideStore](https://sidestore.io/)（初回ペアリング後は iPad 単体で完結）
- サイドロード用の無料 Apple ID

**手順**

1. [Releases](https://github.com/c-colloid/Morpho/releases) から最新の
   `Morpho-x.y.z.ipa` をダウンロード（iPad の Safari でそのまま落とせます）
2. AltStore（＋ボタン → ipa を選択）か SideStore で開く
3. iPad の 設定 → 一般 → **VPNとデバイス管理** → 開発者を信頼

**補足**

- 初回起動時のみ、変換エンジン（pandoc.wasm・55.9 MB）の取得に
  ネット接続が必要です。以後の変換はすべて端末内で行われ、
  原稿が外部サーバーへ送られることはありません
- 無料 Apple ID の署名は7日で切れます。AltStore は AltServer と同一 Wi-Fi に
  いれば自動で再署名します（サイドロード枠は3アプリまで。AltStore 自身が1枠使用）
- Releases はアプリ本体の push のたびに自動でビルド・更新されます（約5分）。
  無いときは GitHub の **Actions タブ → Build IPA → Run workflow** で手動実行もできます

**アップデート**

新しい版が公開されると、アプリ起動時にバナーで知らせます。
入れ替えをワンタップにするには、AltStore / SideStore に Morpho の
「ソース」を一度登録しておきます:

1. AltStore: Browse → Sources → ＋ / SideStore: Sources → ＋ で次の URL を追加

   ```
   https://github.com/c-colloid/Morpho/releases/latest/download/source.json
   ```

2. 以後はストアの Update に新しい版が並び、タップで入れ替えられます
   （AltStore + 常駐 AltServer なら自動更新も効く）。アプリ内の文書は残ります

## 画面と操作

左が**原稿**、右が**プレビュー**。原稿を編集して手が止まると、
約 1.5 秒後に自動で変換されてプレビューが更新されます。
プレビューは変換結果の pptx（実際の出力そのもの）を解析して、
座標・配色・字サイズまで実寸で描画したものです。

| 操作 | 効果 |
|---|---|
| プレビュー右上のセグメント | プレビュー形式の切り替え（**スライド / Web**）。Web は HTML 出力そのものの表示で、発表者ノートは出ない。長押し等の編集操作はスライド形式のみ |
| スライドカードをタップ | 原稿のその区間の先頭へカーソルが移動 |
| 段落を**長押し** | 改行位置の編集シート。「語 / 字」で粒度を切り替え、まとまりをタップした位置で改行。適用すると原稿に行末 `\` が入る |
| カード右上の「**装飾**」 | 装飾パネルを開く。プリセット（上下の帯・アクセント線・角丸カード）を置き、テーマ配色のスウォッチ・不透明度・位置サイズ（1% 刻み・長押しで連続変化）で整える。パネルを開いている間はスライド上の装飾を**直接ドラッグで移動・右下ハンドルでリサイズ**できる（0.5% スナップ）。行のマーク○を2つ以上付けて**グループ化**するとドラッグで一緒に動く。パネルはタイトルバーのドラッグで移動でき、「全スライドへコピー」で統一デザインにできる。装飾は Markdown には入らず文書ごとに保存され、pptx 書き出しに焼き込まれる |
| カード右上の「ノート追加 / ノート ▸ / 編集」 | 発表者ノートの確認と編集（原稿の `::: notes :::` に書き戻される） |
| ヘッダの「▶ 再生」 | 全画面スライドショー。横スワイプ / 左右端タップで送り、下部の「発表者」で発表者ビュー（ノート・次のスライド・経過時間） |
| ヘッダの「書類」 | 文書の一覧・新規作成・切り替え・削除・.md の読み込み |
| ヘッダの「書き出し」 | pptx / docx / md / Obsidian へ送る |

原稿は自動保存されます（手が止まって1秒後 + アプリを離れるとき即時）。
カーソル位置のスライドはプレビューで強調され、自動でスクロールします。

## 原稿の書き方

pandoc の Markdown が基本です。アプリが特別に扱うものだけ挙げます。

| 書き方 | 意味 |
|---|---|
| `# 見出し` | 新しいスライド（`##` 以下はスライド内の見出し） |
| `***` | 明示的なスライド区切り（**`---` は使わない**。front matter と衝突する） |
| 冒頭の `---` `title:` `---` | front matter。title があるとタイトルスライドが1枚できる |
| 行末の `\`（または スペース2つ） | その位置でスライド上の改行を固定。**日本語キーボードでは `¥` が入力されることがあり、`¥` では効かない**。`\` の入れ方: ソフトキーボードは `¥` を長押し、ハードウェアキーボードは **Option + `¥`**（実機で確認済み）。段落長押しの改行編集を使えば常に正しい `\` が入る |
| `- 項目` / `1. 項目` | 箇条書き / 番号付き |
| 半角スペース**2つ**（またはタブ）で字下げ | 箇条書きの入れ子。**半角1つでは入れ子にならず、全角スペースだと箇条書き自体が壊れる**（実測） |
| `::: notes` 〜 `:::` | 発表者ノート。スライドには出ず、pptx のノート欄に入る |
| `**太字**` `*斜体*` `` `コード` `` | 書式。和文の斜体は iOS の日本語書体に斜体字形が無いため傾かない |

和文の一文を原稿内で複数行に折り返して書いても、半角スペースは混入しません。

## 書き出しと連携

| やりたいこと | 手段 |
|---|---|
| PowerPoint / Word で開くファイルを作る | 書き出し → pptx / docx → 共有シート →「"ファイル"に保存」（iCloud 含む。同名なら置き換え） |
| 原稿（.md）をバックアップ・共有する | 書き出し → md |
| Obsidian にノートとして送る | 書き出し →「Obsidian へ送る」（実験的。最後に開いた保管庫へ。本文約2万字まで） |
| Files / Obsidian 保管庫の .md を取り込む | 書類 →「読み込み」（アプリ内にコピーされる） |

読み込みはコピーなので、**元ファイルへのその場の上書き保存はできません**。
Obsidian 保管庫との往復は「読み込み → 編集 → md 書き出しで同じ場所に置き換え」で
回ります（ファイル名は文書タイトルから付くので、タイトルを変えなければ揃います）。

## 既知の制約

- 表はプレビューにまだ描画されません（書き出した pptx には入ります）
- プレビューの行の折り返し位置は、PowerPoint のフォントメトリクスと
  完全には一致しません
- 元ファイルへのその場の上書き保存（open in place）は未対応です
